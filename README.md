# BillPrinter
Contributors: Jan Čihař, Maksym Solonityn, Filip Heger, Kristýna Šachová
Simple bill printer.

## Requirements 
- OpenJDK-27

## How to use
1. Download jar file from release
2. You need to make products.txt or download the sample with all your products in form ID,NAME,PRICE
3. Run the program
